Small cheat sheet of the terms used in Apple's API. As someone coming from win32, I'm not as familiar with everything.
- **Cocoa** - Apple's native OOP interface. Headers compatible with both C/C++, Objective-C and Swift. Cocoa is used to develop both Mac an iOS apps.
- **Foundation** - Objective-C platform API developed originally for NeXT, this was rolled into Cocoa when Apple acquired NeXT Computers. The data types all start with NS for NextStep. e.g. NSObject, NSString, NSSet.
- **AppKit** - UI toolkit component of Cocoa. Built off of Foundation, the data types are also prefixed with NS.
