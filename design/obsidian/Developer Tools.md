A collection of developer tools I've found useful

## Git
 * [Tortoise Git](https://tortoisegit.org/) - Windows shell extension which adds git status to the  
 * [Turtle Hub](https://github.com/dail8859/TurtleHub/tree/master) - GitHub issue tracker plugin for tortoise

## IDEs
* [Android Studio](https://developer.android.com/studio) - Based on InteliJ, for Android development only. Requires a [plugin](https://doc.qt.io/qttoolsforandroid/) to integrate with Qt
* [Qt Creator](https://www.qt.io/development/tools/qt-creator-ide) - Best integration with Qt build tools, but worst at everything else
* [Visual Studio Community Edition](https://visualstudio.microsoft.com/vs/community/) - My preference for development, but only windows support
* [Visual Studio Code ](https://code.visualstudio.com/?_exp_home=e855cfac50) - Cross platform, and Qt integration via plugin, but still figuring out the configuration 

## Visual Studio Code Plugins
* [Markdown Lint](https://marketplace.visualstudio.com/items?itemName=DavidAnson.vscode-markdownlint) - Provides linting for markdown files
* [Markdown Preview Enhanced](https://marketplace.visualstudio.com/items?itemName=shd101wyy.markdown-preview-enhanced) - A better markdown preview
* [CMake Tools](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cmake-tools) - Dependency for building Qt CMake projects
* [Qt Core](https://marketplace.visualstudio.com/items?itemName=TheQtCompany.qt-core) - Dependency for the Qt C++ plugin
* [Qt C++](https://marketplace.visualstudio.com/items?itemName=TheQtCompany.qt-cpp) - Needed to build Qt projects in visual studio
* [Trailing Whitespace Visualizer](https://marketplace.visualstudio.com/items?itemName=MadsKristensen.TrailingWhitespace64) - Highlights and removes trailing whitespace automatically

## Visual Studio Plugins
 * [Graphical Debugging](https://marketplace.visualstudio.com/items?itemName=AdamWulkiewicz.graphicaldebugging-vscode) - Provides visualization of geometric data types
 * [Markdown Editor v2](https://marketplace.visualstudio.com/items?itemName=MadsKristensen.MarkdownEditor2) - Markdown support for visual studio 
 * [Markdown Lint](https://marketplace.visualstudio.com/items?itemName=MadsKristensen.MarkdownLint) - Support for markdown lint within VS IDE
 * [Qt Visual Studio Tools](https://marketplace.visualstudio.com/items?itemName=TheQtCompany.QtVisualStudioTools2022) - Needed for building Qt projects within Visual Studio
 * [SVG Viewer](https://marketplace.visualstudio.com/items?itemName=MadsKristensen.SvgViewer) - SVG preview, needed since most icons in my app are SVGs
 * [Trailing Spaces](https://marketplace.visualstudio.com/items?itemName=shardulm94.trailing-spaces) - Highlights and removes trailing whitespace automatically

## Misc.
 * [GrepWin](https://github.com/stefankueng/grepWin) - From the creator of Tortoise Git and SVN. Adds Grep to the windows file explorer
 * [WireShark](https://www.wireshark.org/) - Network packet analysis
 * [Windows PowerToys](https://learn.microsoft.com/en-us/windows/powertoys/) 
	 * Colour picker for getting a colour hex code
	 * Power rename for batch renaming files
	 * File locksmith for determing file locks
